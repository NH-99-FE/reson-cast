# 图片分发

- UploadThing 保存上传及 AI 生成的原图，视频封面保持 private ACL，不在上传端重复生成展示尺寸。
- 公开自定义封面、公开主页横幅使用 Next Image；部署到 Vercel 时由其图片优化服务及 CDN 提供响应式图片。
- 图片源入口接受上传端的 image 类型。SVG 经 Next 图片入口原样供图，不做光栅转换；源入口及优化入口均使用沙箱 CSP 和 attachment 响应头。
- Mux 提供默认封面和动态预览，不重复交给 Next 优化。公开默认封面通过固定版本入口提供图片内容，服务端在缓存未命中时签名取图；浏览器不接收 Mux 签名 URL。视频列表、播放列表封面宽度 640，播放器宽度 1280。预览宽度 480、8fps；预览首次交互时加载，离开或触摸结束后隐藏并保留图片元素，后续交互直接复用，直到卡片卸载。预览地址变化后需重新交互加载。首页提前连接 image.mux.com。
- 工作台列表、编辑页缩略图和播放器封面按视频已保存的可见性分流：公开视频复用前台的版本化公开地址和缓存，自定义封面使用 Next Image，Mux 小图宽度 640、播放器封面宽度 1280。公开地址不附加刷新参数，更换封面或播放 ID 时由版本化地址更新。
- 私有视频图片和动态预览通过应用鉴权，307 跳转到 60 秒有效的签名地址，跳转响应不缓存。签名在有效期内可转发。

## 公开封面与权限

公开封面源入口 `/api/public/video-thumbnails/:videoId/:version` 只接受当前公开、未删除且封面版本匹配的视频，不以作者身份放行。源文件仍保持私有，由应用读取并提供给优化器，源响应本身不缓存。私有图片入口不在优化器白名单中。

版本由文件 key 派生，更换封面会生成新 URL，无需主动刷新旧缓存。旧源图入口在版本变化、转私有或删除后拒绝访问。

公开 Mux 默认封面入口 `/api/public/video-mux-thumbnails/:videoId/:version/:width` 只接受当前公开、未删除、无自定义封面且播放 ID 版本匹配的视频，宽度仅允许 640 或 1280。版本由当前 Mux 播放 ID 派生，返回 `public, max-age=3600, s-maxage=3600, must-revalidate`，允许浏览器和 CDN 缓存 1 小时；错误响应不缓存。切换至自定义封面或轮换播放 ID 后，新页面使用新地址，旧入口在缓存未命中时拒绝访问。Mux 控制台直接修改默认封面时间而不轮换播放 ID 时，旧图可能保留到缓存过期。该缓存入口是应用的分发设计，Mux 上游仍遵循官方签名规则。

**曾公开的封面允许继续通过已有浏览器或 CDN 缓存地址访问。** 转私有、换图、删除视频或账号均不主动撤销已有图片缓存；自定义封面的缓存交给优化器及 CDN 自然管理，不承诺旧地址的失效时间；Mux 默认封面入口允许缓存 1 小时。视频播放权限独立处理，不能以封面缓存是否存在判断视频可见性。已经下载的图片也无法收回。

不引入图片缓存撤销任务表、数据库触发器、定时扫描器或额外部署配置。原有文件清理流程继续处理源文件的替换和删除。

## 验证

- 前台与工作台的公开自定义封面使用 `/_next/image` 和响应式 srcset；公开 Mux 默认封面直接使用固定版本地址，私有封面和动态预览仍使用鉴权跳转。
- 无权限的用户无法通过应用入口获取私有图片；公开源入口拒绝旧版本、私有及已删除视频。
- 换图后使用新 URL；转私有后源入口拒绝访问，但已缓存的公开封面可能继续可见。
- 动态预览在交互前不请求，加载中或失败时继续显示静态封面；加载成功后重复悬停或触摸复用同一图片元素，不新增请求，离开、触摸结束或取消时隐藏预览。加载失败时移除失败元素，下次悬停或触摸重新请求，不在当前交互中自动循环重试。

本地测试覆盖入口权限、版本匹配、图片分流和预览交互；实际 Vercel 缓存命中和存储签名需部署联调。

浏览器测试以真实 HTTP 响应验证公开 Mux 封面跨文档访问时 `transferSize=0`、图片内容有效且没有第二次权限查询或上游取图；测试中只模拟数据库结果和 Mux 响应，不依赖线上凭据。浏览器清理缓存、强制刷新或开发工具禁用缓存时仍可重新请求。
